# Lexicon Godot SDK

Copy this folder to any Godot 4 project at `addons/lexicon`. Lexicon's external editor does this when saving. Enable **Lexicon** in Project Settings > Plugins for a three-tab catalog dock; select an entry to inspect its Resource. Reload master list after exporting while the editor is open. No autoloads or Remnant systems are required.

Assign `lexicon/lexicon_db.tres` to a LexiconPlayer, or instance `addons/lexicon/player.tscn` and assign its Database. Call `play("dialog", "conversation_1")`, `play("flavor", "flavor_1")` or `play("notes", "note_1")`. The optional presenter types caption text, accepts E to advance, waits for optional voice before automatic advancement, offers choice buttons and shows image/text notes. Default note presentation is an editable prototype; use your game's physical note UI if available. Empty audio/image fields are safe. Configure timing, key and voice bus on the presenter; absent Vocals falls back to Master.

For custom/in-world presentation, omit Presenter. Bind line_started, choices_requested, note_requested, content_finished, playback_cancelled and content_error. Call advance() after a line; choices_requested supplies ordered label/target choices, and choose(index) follows one. Empty targets end. cancel() clears playback state and emits playback_cancelled so hosts can clear their UI/audio. Branch loops are allowed and move only on explicit advancement. LexiconTrigger connects any host interaction/look/area system to the player through trigger()/interact(); it does not introduce its own raycast, prompt or save layer.

LexiconNote holds id/title/text/image. LexiconConversation holds id/title/start_line and ordered line Dictionaries with id/speaker/text/audio/next/choices. LexiconFlavor has linear line Dictionaries. LexiconCatalog.entries and find(id) feed LexiconDatabase.notes/dialog/flavor and find(kind,id). All resources use @tool; no live Nodes are serialized in them. Keep IDs stable once referenced in a game's flags or triggers.

Presenter.voice_handler is an optional Callable(AudioStream)->Node with finished or playback_finished and stop(); its generation guard ignores callbacks from a replaced clip. Presenter.note_handler is an optional Callable(LexiconNote). A supplied host audio service must return a handle owned until its completion; do not stop a reused pooled handle after completion. Remnant's Scripts/Dialogue/lexicon_remnant_bridge.gd provides pooled Vocals and existing physical Notes.collect integration; it is deliberately outside the portable addon.

The external editor owns generated files through lexicon/.lexicon-manifest.json. Saving copies assets, updates all catalogs/master resources and prunes only unused owned files. lexicon/lexicon.source.json is the portable editable source for reopening or agent authoring. Unmanaged files and modified obsolete files are protected. Do not hand-edit the ownership manifest. Source/tool instructions are in Tools/Lexicon/README.md in the authoring repository.

The optional Presenter makes the mouse visible for its own choices and notes and restores the prior mode on close/cancel. Custom hosts should omit it or coordinate their own modal input ownership through the content signals. It does not pause a game's movement or override a host pause system. Its default captions/notes are a reusable draft; Remnant uses physical in-world notes through its bridge.
