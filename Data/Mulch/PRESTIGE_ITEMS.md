# Grind Additional Items / prestige items

The Mulch tab now includes Grind Additional Items: a one-time permanent unlock costing 500 banked mulch pellets/coins. Edit Data/Mulch/grind_additional_items.tres to tune its price. It is intentionally expensive compared with ordinary permanent upgrades and is a prerequisite for the future true ending. This change adds the permission, not new story items or ending triggers.

The editor global group is named exactly prestige items (with a space), registered in project.godot. Add future objects to it on the RigidBody3D or their item wrapper root. Keep ordinary item scene structure, pickup prompts/target shapes, score/grindable groups and score_object if they should award score/mulch. An unlocked tagged rigid body can be targeted/picked up even without the pick-up tag; wrapper roots should retain the usual pick-up body group so the ray resolves their collider correctly. The group does not override machine-immune or turn static scenery into a physics item.

Global/mulch.gd (Mulch / Node autoload) exposes prestige_items_unlocked()->bool from SaveGame.profile.mulch_upgrades[grind_additional_items]. It works before a terminal registers a catalog and remains enabled across reload and New Game. The existing tab unlock still requires current-run Mulcher and Bin purchases to buy it. Delete Save removes profile permissions as before. Future ending triggers can call Mulch.prestige_items_unlocked(); do not infer it from regular score or reset run flags.

physics_items.prestige_locked(node) walks the item ancestry and tests the persisted permission. raycaster excludes locked tagged targets, including a normal pick-up child under a tagged wrapper. player_pickup.pickup_object rejects them before changing cargo/collision ownership. Rail station/car cargo also rejects locked items, preventing a carried assembly bypass. Multi-grab, basket capture and vacuum feedstock use is_processable, which applies the same gate; the grinder also uses it. Unlocking makes existing objects available immediately. Grinding then retains ordinary once-only root cleanup, score/combo and mulch consumption. Items already touching a grinder while locked need a later entry; they cannot be handled before the unlock through normal pickup.

Resource id grind_additional_items, title Grind Additional Items, tab MULCH=3, base_cost=500, max_level=1. This feature uses its saved permanent level as the permission and has no numeric effect array. Existing generic purchase caps prevent duplicate spending; ordinary run score is not charged. The default catalog has nine Mulch entries and the actual in-world PC screen displays the price/completion state.

Tests/prestige_items_test.tscn covers global-group registration, wrapper-to-body targeting, scripted pickup denial, processing/grinding denial, insufficient pellets, immediate unlock, exact once-only currency charge, ordinary grinder ownership, actual profile file reload and New Game persistence. No new prestige scenes enter the spawn pool yet.
