# Runtime debug inspectors

The current implementation is portable under addons/dev_toolkit; the original Global/script paths are compatibility wrappers. See Data/DEV_TOOLS.md for adapter, resource commands, canonical scripts and API identities.
F2 opens Blackboard, F3 opens Flags, F4 opens the actual save file. Available from title, gameplay and paused menus. Press the same key again or Escape/Close to close; press a different inspector key to switch. Each view is a selectable, read-only scrollable text list with REFRESH. The game pauses while inspecting and resumes its previous pause/mouse/input state on close. Lists are snapshots refreshed manually, not continuously.

Blackboard includes all keys sorted by name, nested arrays/dictionaries expanded, primitive values and transforms displayed. Node references show only their node name; Resources show their name, filename or class; freed objects are identified. False flags are shown as well as true ones. The inspector's temporary player_input_blocked override is replaced with the original value in its Blackboard view. Recursion is guarded after 32 levels for cyclic/deep containers.

F4 reads SaveGame.save_path using FileAccess.get_var(false), without instantiating objects, decoding resources, loading the run or writing/autosaving on demand. It shows absolute path, byte size and all stored payload fields including version, profile, Blackboard and flags. Encoded resource/runtime references remain their stored representation, useful for inspecting persistence. Missing/unreadable/invalid saves produce an explanatory message. Unsaved runtime changes will only appear in F2/F3 until the normal save system writes them.

Implementation: Global/debug_inspector.gd is a compatibility wrapper, UID uid://cgbc6vh57gq03; DebugInspector autoload, layer90, PROCESS_MODE_ALWAYS. The CanvasLayer core is addons/dev_toolkit/debug_inspector.gd, exporting tools_context, enabled and the three inspector keys. Runtime: is_open, context, mode, heading, content; DevToolsContext owns prior pause/mouse/input state. API: open_inspector(key:int), close_inspector(), refresh_view(), read_save_text()->String, format_value(value:Variant,depth:int=0)->String. The adapter supplies values, flags and the configured disk save; formatting is shared through context. _input handles F2/F3/F4/Escape. Underlying pause/options/computer/dialogue input handlers return while inspecting. F1 replaces the inspector with IssueReporter; inspector shortcuts are ignored while reporting to preserve the draft. Tests/debug_inspector_test.tscn verifies nested node names, flags, refresh, stored data without mutation/loading, missing saves and modal restoration.
