# Reusable development reporting

Skills/development-reports/SKILL.md and the installed $development-reports skill now define the exact HTML summary format for this and future projects. The skill includes assets/report_theme.css (the same current project theme), a self-contained HTML starter template, and references/remnant.md with configured delivery paths. The installed Godot workflow points to it for reports.

The preferred style is warm paper, dark ink, rust and restrained acid accents, large bold headings, monospaced labels/dates, square feature rows and thin rules. Each dated chapter uses a stable unique fragment ID, eyebrow, h2, lead, concrete behavior/controls, parallel feature descriptions, evidence/limits, actual build details and a real source commit link. Old chapters remain accessible. Images must be actual reviewed captures and final galleries embed them for offline use. Mobile layout and functional search/navigation are checked in a real browser.

Meaningful development prompts maintain README and guides, timestamped guide log, wiki content/sidebar/search, summary history and searchable archive. Append the actual verification/build/source/summary outcome to the existing Notion Agent Workflow Log after fetching it, preserving history. The skill does not publish local F1 reports, saves, recordings or private logs, and other projects use their own remote and authorization.

Primary report host: https://coolbeangames.github.io/Remnant-GD/. Existing GitHub Pages Actions packaging/deployment remains in place; no visibility or account changes. Reports/index.html is the local archive; hosted /Archive/index.html, /Wiki/index.html and /Topic/index.html galleries share navigation. Tools/rebuild_report_index.py, rebuild_wiki.py and build_documentation_site.py preserve history and validate links/IDs/search. Check the successful deployment for the pushed commit and hash the actual published files against build-info.json before claiming completion. Older private-site access is retained unchanged.

Skill sources and template/theme are versioned under Skills/development-reports; its discoverable copy is installed under the user skills folder. Frontmatter/reference validation and actual responsive template use are part of this delivery. A small delivery-record commit may record actual source/deployment outcomes without needing another unchanged game build.
