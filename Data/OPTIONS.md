# Title and shared Options

Project startup is Scenes/UI/title_screen.tscn. New Game clears the saved run while retaining banked mulch coins, purchased permanent mulch tiers and settings, then enters Scenes/save_loader.tscn → Game → testing_level. Continue appears only when a valid saved run exists, and restores that run through the same intermediary. A profile-only file from settings/New Game does not enable Continue. Options opens the same reusable menu as pause-menu Options. Exit uses SaveGame's safe quit flow.

TitleScreen is a Node3D with the designer's grinder workshop under Background and an active Camera3D. UI/Screen fills the window; its Rows contain editable NewGame/Continue/Options/Exit buttons. Main-scene startup no longer enters gameplay automatically. Preserve the authored background, camera transform, lighting and button layout when editing menu behavior.

The optional Machine Audio export references Background/testing_level/game_stage_base/MachineRun. Title startup and clip completion use Audio.set_spatial_active to play/restart this authored AudioStreamPlayer3D on SFX. Its stream, attenuation and -6 dB local gain remain editable on the player; the shared Master/SFX sliders still apply. It processes while Options pauses the scene and stops when title exits. An absent player or empty stream is safe and silent.

Normal windowed Play starts maximized once through Settings._ready. A saved Fullscreen setting takes precedence. The existing canvas-items stretch with Expand aspect renders across the available window, adapting to wide/tall shapes without letterboxing. Later resizing, Settings.restore and unrelated graphics changes do not force the window back to maximized. Camera framing changes with the aspect ratio; the authored scene framing remains intact.

Options has Master, SFX, Vocals and Music sliders (0–100%), separate mouse X/Y inversion, sensitivity multiplier (0.1–5), Back and DELETE SAVE AND EXIT. Controls apply immediately and persist after a short 0.25-second debounce or when closing. A shared options_menu CanvasLayer owns its pause/mouse state, restoring the caller's previous pause on Back/Escape. From pause it returns to a still-paused game; from title it returns to title. Delete Save moved off the main pause menu. It removes the entire file/profile, including banked coins/tiers, and quits without saving. Any failure appears in the Options status label; deletion is checked against the resolved absolute path and verified afterward.

Options separates Audio, Controls and Graphics into scrollable tabs. The menu resizes its content area with the window, leaving Back and Delete Save accessible. Graphics settings apply live and persist in the same profile, including across New Game:

- Display Mode: Windowed or borderless Fullscreen. A manually maximized window stays maximized when unrelated graphics settings change.
- V-sync: controls the main window's swap synchronization. The display can limit the actual frame rate below the selected cap.
- Frame Rate Limit: Unlimited, 30, 60, 90, 120, 144, 165 or 240 FPS, applied through `Engine.max_fps`.
- 3D Render Scale: 50–100%, in 5% increments, changes the actual 3D buffers using bilinear upscaling. HUD and menu text remain at native resolution.
- Antialiasing: Off, FXAA, MSAA 2×, 4× or 8×; selects one mode, without stacking FXAA/TAA over MSAA.
- Shadow Quality: Low, Medium, High or Ultra changes local shadow atlases from 1024 through 8192 pixels and directional atlas/filter quality. Light activation and authored shadow casting stay intact.
- Ambient Occlusion: disables/restores the authored SSAO on registered environments; it does not add the effect to environments where it was never authored. The workshop uses SSAO; the portal room's authored environment remains unchanged. SSAO requires Forward+.

`Settings.apply_viewport(viewport)` applies scale, antialiasing and local shadow resolution; `Settings.graphics_revision` allows secondary viewports to refresh only when settings change. The story door uses this API when its viewport is created and on revision changes, so its render buffers match the main game. `Settings.register_environment(environment)` keeps a weak reference plus the original SSAO setting. WorldEnvironment/Camera3D additions register their environment automatically after entering the tree; a system assigning a different environment later should call this API. All setting values are normalized on profile restore; old saves obtain new defaults and invalid enums/frame caps cannot reach the renderer.

Master controls Master, SFX controls SFX plus RoomSFX, Vocals controls Vocals, Music controls Music. Spoken dialogue, jump grunts, sprint breathing, death clips and intro exertion now use Vocals. Slide/room effects remain RoomSFX. Footsteps bus routes to RoomSFX so footsteps stay audible during initial world muting but respect the SFX slider. start_room tracks Settings revision while gating SFX; if settings change, opening restores the current configured gain, not the earlier value or full gain. World gating only mutes SFX; it never overrides the other sliders. Mouse settings multiply the authored look sensitivity and invert axes independently.
