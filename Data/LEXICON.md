# Lexicon / reusable story authoring

Lexicon is a separate Windows tool for notes, branching dialog and linear flavor content. Its three tabs maintain searchable master lists, stable IDs, images, transcripts and optional per-line voice. Preview content before Save + Export. Browse selects any Godot project; Open reloads its portable editable library. Ctrl+S saves and exports. Exit Tool closes the local process.

The installed SDK lives at `addons/lexicon`. Enable its editor plugin for a catalog dock, then instance `player.tscn` and assign `lexicon/lexicon_db.tres`. Use play(kind, id), advance(), choose(index) and cancel(), or connect the content signals to an existing in-world presentation. No autoloads or Remnant services are required in other games. Optional draft presentation waits for voice or E, restores mouse mode after choices/notes and clears text/audio on cancellation.

Export structure: `lexicon/lexicon_db.tres`; `lexicon/notes/note_db.tres`, individual notes and `images/`; `lexicon/dialog/conversation_db.tres`, conversations and `vocals/`; `lexicon/flavor/flavor_db.tres`, flavor entries and `vocals/`. Asset filenames use content hashes. `lexicon.source.json` is the editable portable source. `.lexicon-manifest.json` tracks generated-file ownership. Only obsolete owned files are removed; shared assets remain while referenced. Validation happens before writing, replacement failures roll back and unchanged files avoid reimport churn.

Remnant integration is optional through Scripts/Dialogue/lexicon_remnant_bridge.gd: assign a Presenter to route voice through pooled Vocals and notes through Notes.collect, the physical note view, journal and existing saves. LexiconTrigger delegates to the host's interaction/look system. It does not replace prompts, inputs, progression flags or existing authored scenes automatically. For in-world conversations, connect LexiconPlayer signals to the game's own presentation rather than adding a competing full-screen interface.

Authoring instructions and JSON/CLI details: Tools/Lexicon/README.md. SDK APIs and resources: addons/lexicon/README.md. Latest local executable: Builds/latest_lexicon.txt. Build helper: Tools/build_lexicon.py. The game and tool have separate Windows packages. CLI export supports deterministic content edits by future agents. Read current project instructions, this guide and the source library before authoring; preserve stable IDs and unrelated content.

Verification covers exporter ownership/shared media/rollback, local server revision and origin boundaries, actual browser uploads/branches/save/reopen at desktop and phone widths, and Godot resource/runtime behavior in an isolated project without Remnant dependencies. Draft UI is optional; connecting new authored content to specific story triggers remains a separate design task.
